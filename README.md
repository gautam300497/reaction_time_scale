# Reaction Time Scale ⏱️

A simple, interactive web application to test and categorize your reaction speeds.

## Features
* **Randomized Start**: Prevents cheating by using a random delay.
* **Rating System**: Categorizes your speed from "Lightning Fast" to "Are you awake?".
* **High Score**: Saves your fastest time locally in your browser.
* **Live Server Compatible**: Optimized for quick local development.

## How to Play
1. Click the red box to start.
2. Wait for the box to turn **green**.
3. Click as fast as you can!
